# Katisa Technologies

Next.js marketing site for Katisa — websites, IDORA NFC cards, inventory systems, and custom software.

## Stack

- Next.js (App Router)
- Tailwind CSS
- Framer Motion
- Firebase (Firestore)
- EmailJS (webinar OTP / confirmation)
- Calendly + Jitsi (consultation / webinar room)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy (Netlify)

Uses `@netlify/plugin-nextjs`. Build command: `npm run build`.
