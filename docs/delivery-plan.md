# Software delivery plan (internal)

Public summary lives on `/software`. Durations are set in `src/lib/pricing.js`.

## Phases

1. **Discovery** (3–5 days) — Learn process and goals → client gets a scope summary.
2. **Design** (3–7 days) — Layouts and workflow → client approves before build.
3. **Build** (1–4 weeks depending on plan) — Small steps with demos.
4. **Launch** (1–3 days) — Go live, train, hand over docs.
5. **Support** — Fixes and improvements; Website Care plans available.

## Quality standards (public)

- Tested on mobile and desktop
- Secure logins and backups where needed
- Written handover notes
- Training session
- **14 days of free bug fixes after launch**
